# Ripast branding

The README uses **1I, Shared shoulder**, selected from the Brand Lab on 8 October 2026.
The r flows into the i. The mark and custom wordmark share that joined shape.
All letters use SVG paths, with no font dependency.

| File | Use |
| --- | --- |
| `logo-light.svg` | Horizontal logo for light backgrounds |
| `logo-dark.svg` | Horizontal logo for dark backgrounds |
| `mark.svg` | Yellow tile with the ri ligature |
| `source-1I.html` | Original selected card, including 16 px and 32 px samples |
| `lab.html` | Full exploration, with theme toggle, alternate logos, UI motifs, and composition studies |
| `provenance.json` | Skills and exact source revisions behind options 1I to 1L |

Open `lab.html` in a browser to revisit the exploration.
Its alternate directions and recommendations are exploration material, not additional brand selections.
`source-1I.html` uses the lab's CSS variables.

Keep yellow bright in light mode. Use dark ink on yellow fills.
The README exports preserve 1I's original paths in a horizontal arrangement.
The standalone ligature can read as an n. Prefer the full wordmark when introducing Ripast.
