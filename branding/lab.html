Product reasoning and reference studies

Ripast takes reference lookup and coordinated edits out of the agent's conversation. Compact agent output gives it a result to act on.

The selection frame remains the shared shape. The accent identifies the target. It can repeat across code without treating unrelated names as matches.

Verification can block writes that introduce type diagnostics. CSS class rename does not run typecheck verification.

References: Visual Studio Code and ast-grep. The first study's comparison follows.
